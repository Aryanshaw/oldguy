# Phase 2: manifest and local server

This folder holds the paperwork for Phase 2, the part that keeps a list of
chapters and serves them on your own machine.

- README.md: this page.
- ACCEPTANCE.md: the checks that must pass before Phase 2 counts as done.
- SUMMARY.md: what was built, what was proven, what is still weak.
- frames/: screenshots taken while checking the work.

The rules the code follows are in section 14 of the design spec,
docs/superpowers/specs/2026-10-02-yap-design.md.
