# oldguy

Ask the old guy. Installs [oldguy](https://github.com/Aryanshaw/oldguy) into Claude Code.

Claude yaps. You watch.

```
npx oldguy
```

It adds the oldguy plugin to Claude Code (or updates it), then shows what oldguy still needs on this machine, such as the
local voice, with sizes and the exact commands, and sets up only what you tick.

- `npx oldguy --yes` sets up everything offered, without asking.
- `npx oldguy --plugin-only` only installs or updates the plugin.

Needs [Claude Code](https://claude.com/claude-code) and Node 22.18 or newer. macOS or Linux.
