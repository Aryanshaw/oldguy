# getyap

Installs [Yap](https://github.com/Aryanshaw/yap) into Claude Code. Claude yaps. You watch.

```
npx getyap
```

It adds the Yap plugin to Claude Code (or updates it), then shows what Yap still needs on this machine, such as the
local voice, with sizes and the exact commands, and sets up only what you tick.

- `npx getyap --yes` sets up everything offered, without asking.
- `npx getyap --plugin-only` only installs or updates the plugin.

Needs [Claude Code](https://claude.com/claude-code) and Node 22.18 or newer. macOS or Linux.
